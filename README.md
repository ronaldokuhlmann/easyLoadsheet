# easyLoadsheet

Mini site estático para calcular distribuição de malas nos porões dos Airbus A319, A320 e A321.

## Variantes

```text
A319: H1, H4, H5 - principal H4
A320: H1, H3, H4, H5 - principal H1
A321: H1, H2, H3, H4, H5 - principal H3
```

## Publicar no GitHub Pages

Envie para o repositório:

```text
index.html
styles.css
app.js
manifest.webmanifest
sw.js
README.md
```

Depois ative em `Settings > Pages > Deploy from a branch > main / root`.
